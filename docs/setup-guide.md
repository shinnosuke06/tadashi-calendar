# 予定表アプリ 手順書（家族の方へ）

お父さんの iPhone で「予定表」アプリを使えるようにするまでの手順です。
1 回目の設置は、**パソコンと父の iPhone を並べて**、家族が一緒に行うのがおすすめです（1 時間ほど）。

- 予定は**お父さんの Google カレンダー**に入ります。アプリは Google カレンダーを見やすく出す「窓」です。
- 通知は **Google カレンダーのアプリ**から届きます。
- 毎晩 3 時ごろ、予定の**控え**がスプレッドシートに自動で作られます（14 日分）。
- お金はかかりません（地図と天気は、無料の範囲を超えないように回数の上限を付けています）。

## 1. アプリを公開する（GitHub）

アプリの画面は GitHub Pages という無料の置き場所から配ります。最初に 1 回だけ、GitHub の画面（パソコンのブラウザ）で行います。

1. **Pages を有効にする**: リポジトリの上の **Settings** → 左の **Pages** → **Build and deployment** の **Source** を **GitHub Actions** にします。
2. **main ブランチを作る**: リポジトリの **Code** の画面で、左上のブランチ名のボタン（`claude/` で始まる名前）を押し、`main` と入力して **Create branch main from claude/…** を押します。
3. **main をいつものブランチにする**: **Settings** → **General** → **Default branch** の **⇄**（切り替え）ボタン → **main** → **Update** → 確認の画面で **I understand, update the default branch.** を押します。
   （公開は「いつものブランチ」からしか許されないためです）
4. **公開する**: 上の **Actions** → 左の「**公開（GitHub Pages）**」→ 右の **Run workflow** → ブランチが **main** になっていることを確かめて **Run workflow**。緑のチェックになるまで待ちます（数分）。
5. **Settings** → **Pages** に出る公開アドレスを控えます。
   形は `https://（GitHub の名前）.github.io/tadashi-calendar/` です。

2 回目からは、直した内容を **プルリクエスト** で main に入れる（**Merge**）と、自動でテスト → 公開されます。
iPhone のアプリは、次に開いたときに新しい版に切り替わります。

## 2. Google 側の準備（パソコン）

**お父さんの Google アカウントで**ログインして行います。ほかの人のアカウントで作ると、その人のカレンダーにつながってしまいます。

### 2-1. スプレッドシートと Apps Script を作る

1. Google ドライブで **新規** → **Google スプレッドシート** → **空白のスプレッドシート** を作ります。名前は「予定表 データ」などにします（控えと設定がここに入ります）。
2. スプレッドシートの上のメニューで **拡張機能** → **Apps Script** を開きます。
3. 左上の「無題のプロジェクト」を押して、名前を「予定表」などにします。

### 2-2. コードを貼る

1. 左の **歯車（プロジェクトの設定）** を開き、**「appsscript.json」マニフェスト ファイルをエディタで表示する** にチェックを入れます。
2. 左の **エディタ（`< >` の印）** に戻ると、ファイルの一覧に `appsscript.json` が出ます。
3. `appsscript.json` を開き、中身をすべて消して、このリポジトリの [`gas/appsscript.json`](../gas/appsscript.json) の中身を貼り付けます。
4. `コード.gs` を開き、中身をすべて消して、このリポジトリの [`gas/dist/Code.gs`](../gas/dist/Code.gs) の中身を貼り付けます。
5. 上の **保存（フロッピーの印）** を押します。

> `appsscript.json` を貼ると、Google カレンダーの機能（Calendar API）が自動で有効になります。
> 左の **サービス** に「Calendar」が出ていれば OK です。出ていなければ、**サービス** の **＋** → **Google Calendar API** → **追加** を押します。

### 2-3. `setup` を実行して、許可する

1. 上の関数の選択欄で **`setup`** を選び、**実行** を押します。
2. 「承認が必要です」と出たら **権限を確認** を押し、お父さんのアカウントを選びます。
3. 「**このアプリは Google で確認されていません**」と出たら、左下の **詳細** を押し、
   **「予定表（安全ではないページ）に移動」** を押します。
   （自分で作ったプログラムなので、この表示が出るのは普通です）
4. 許可の一覧が出たら、**すべて選択** にチェックを入れて（チェック欄が出たとき）、**続行**（または **許可**）を押します。
5. 下の **実行ログ** に「設定が終わりました。合言葉: ……」と出れば成功です。

`setup` は次のことをします（何度実行しても大丈夫です）。

- 合言葉を作る
- スプレッドシートに「設定」のシートを作る
- 毎晩 3 時ごろの控え（`nightlyBackup`）を自動で動くようにする

### 2-4. ウェブアプリとして公開する

1. 右上の **デプロイ** → **新しいデプロイ** を押します。
2. 「種類の選択」の **歯車** → **ウェブアプリ** を選びます。
3. 次のように選びます。
   - 説明: 「予定表」など（何でもよい）
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. **デプロイ** を押します。（ここでも許可を求められたら、2-3 と同じように進みます）
5. 出てきた **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を **コピー** して控えます。

> 「アクセスできるユーザー: 全員」でも、**合言葉を知らない人は何もできません**。URL と合言葉は家族の中だけで保管してください。

### 2-5. 合言葉を控える

1. 関数の選択欄で **`showKey`** を選び、**実行** を押します。
2. 実行ログに出た「合言葉: ……」の英数字を控えます。

URL と合言葉は、メモアプリや家族の LINE などで iPhone に送っておくと、次の手順で貼り付けるのが楽です（送った後は消しておくと安心です）。

## 3. iPhone にアプリを入れる

1. iPhone の **Safari** で、1 章で控えた公開アドレスを開きます。
2. 下の **共有ボタン**（四角から上向きの矢印）を押し、**ホーム画面に追加** を押します。
   - 名前は「予定表」のままで **追加** を押します。
   - 「Web アプリとして開く」の切り替えが出たときは、オンのままにします。
3. **必ずホーム画面の「予定表」アイコンから開きます。**
   Safari で開いたままだと、アプリの保存場所が別になり、設定が引き継がれません。
4. 「初めの設定（家族の方へ）」の画面で、
   - **Google 側のアドレス** に、2-4 で控えた URL を貼ります。
   - **合言葉** に、2-5 で控えた合言葉を貼ります。
5. **つなぐ** を押します。月の表が出れば完了です。

> 設置の前に試したいときは、「お試し（見本の予定で使う）」で見本の予定を触れます。本番の予定には影響しません。あとで 家族向けの設定 → **接続をやり直す** から本番につなぎ直せます。

## 4. Google カレンダーのアプリと通知

予定の通知は、Google カレンダーのアプリが出します。

1. App Store で **Google カレンダー** が入っているか確かめます。なければ入れて、**お父さんのアカウント**でログインします。
2. 初めて開いたときの「通知を送信します。よろしいですか？」は **許可** を押します。
   あとから確かめるときは、iPhone の **設定** → **アプリ** → **Google カレンダー** → **通知** → **通知を許可** がオンになっていること。
3. ホーム画面に **ウィジェット** を置きます: ホーム画面の何もないところを長押し → 左上の **編集** → **ウィジェットを追加** → **Google カレンダー** → 好きな大きさを選んで **ウィジェットを追加**。
4. **通知の二重を避けます。** 同じ予定が次のアプリにも出ていると、通知が 2 回来ます。
   - iPhone 標準の「カレンダー」に Google のアカウントを入れている場合: **設定** → **アプリ** → **カレンダー** → **通知** → **通知を許可** をオフ。
   - 今使っている「シンプルカレンダー」も同じ予定を出している場合: シンプルカレンダーの通知をオフにする（アプリ内の設定、または **設定** → **アプリ** → シンプルカレンダー → **通知**）。

### 通知について知っておくこと

- 予定を入れるときに「通知する／しない」とタイミングを選べます。新しい予定には、はじめから「前日（同じ時刻）」と「1時間前」が付いています。**よく使う予定**ごとに、はじめの通知を変えられます（設定 → よく使う予定）。
- 1 つの予定に付けられる通知は 5 個までです（Google の決まり）。
- **終日の予定**は「当日の朝」の通知が付けられません（Google の決まり）。代わりに「前日の朝」「前日の夜」などを選べます。
- 「出発の目安」の時刻に通知を出すこともできます（場所を入れて、移動時間が計算できたとき）。

## 5. 自宅の住所・文字の大きさ・色

アプリの右上の **設定** から変えます。

- **自宅の住所**（移動時間の計算に使います）: **家族向けの設定** を開く → 自宅の住所 → **地図で探して登録する** → 住所を入れて **探す** → 候補を選ぶか地図を押す → **この場所にする**。
- **文字の大きさ**: 5 段階。お父さんに実際に見てもらって選びます。
- **色**: 「白」「さくら」「わかば」「クリーム」「黒地に白」「くっきり」から選べます。
- **読みやすい文字の形（UD フォント）**: オンにすると、数字や文字の見分けがつきやすい字体になります。
- **月のめくり方**（「表示」の中）: 「左右にめくる（横）」（はじめの設定）か「上下にスクロール（縦）」を選べます。
- **予定の種類**（名前と色）、**よく使う予定**、**持ち物セット**、**出発の目安**（余裕の時間など）も、ここで直せます。

設定はスプレッドシートの「設定」シートにも保存されるので、iPhone を買い替えても引き継げます。

## 6. 今のアプリからの引っ越し

引っ越すのは**これから先の予定だけ**です。過去の予定は今のアプリに残しておきます。
新しいアプリに慣れるまでは、**今のアプリを消さずに残して**おきます。

### 6-1. 今の予定がどこに入っているか確かめる

1. お父さんの iPhone で、今使っているアプリ（シンプルカレンダー）の名前を確かめます。
2. iPhone 標準の **カレンダー** アプリに、同じ予定が出ているか確かめます。
   - **出ていて、Google のカレンダーに入っている**（予定を開いて「カレンダー」の欄が Google のもの）: すでに Google にあるので、**引っ越しは不要**です。新しいアプリにもそのまま出ます。
   - **出ていて、iCloud や「この iPhone」のカレンダーに入っている**: 標準のカレンダーで予定を開き、**編集** → **カレンダー** を、お父さんの Google のカレンダーに変えて移します。
   - **出ていない**: 今のアプリが自分の中に予定を保存しています。新しいアプリで先の予定を入れ直します（「よく使う予定」を先に登録しておくと早いです）。

### 6-2. LINEカレンダーに残っている予定（スクショから取り込む）

お父さんが前に使っていた **LINEカレンダー**の中の予定は、Google に移したり書き出したりできません。
そこで、初めの 1 回だけ、**スクショから取り込み用のファイルを作ります**。読み取りは Claude（チャット）が行います。

1. LINEカレンダーで、予定が「LINE」のカレンダーにあるか、「Google などスマホのカレンダー」にあるかを確かめます。Google にある分は引っ越し不要です。
2. LINE にある予定のうち、**これから先の分**をスクショします。
   - 一覧（リスト）の表示があれば、それを撮ります。
   - 月の表しかなければ、月の表に加えて、**時刻が見える画面**（予定を押した画面など）も撮ります。月の表には時刻と場所が出ず、名前も途中で切れるためです。
   - 有料版にしないと見られなくなる前に、早めに撮ります。
3. スクショを Claude とのチャットに貼ります。Claude が日付・時刻・タイトル・場所・メモを読み取った一覧を出すので、お父さんと一緒に確かめて直します。繰り返しの予定らしいものは、繰り返しにするかを聞かれます。
4. Claude が **取り込み用のファイル（.json）** を作ります。iPhone に保存します（「ファイル」アプリなど）。
   **このファイルにはお父さんの予定が入っています。GitHub のリポジトリには入れないでください。**
5. アプリの **設定** → **家族向けの設定** → **まとめて取り込む** でファイルを選びます。
6. 取り込む予定の一覧が出ます。チェックを確かめて **取り込む** を押します。
   - 同じ日・同じ時刻・同じタイトルの予定がすでにあれば、自動で飛ばします。
   - 通知と種類の色は、新しく入れる予定と同じいつもの設定で入ります。
7. 取り込みが終わったら、iPhone に保存したファイルは消して構いません。

## 7. 実機での確認表

設置が終わったら、お父さんの iPhone で 1 つずつ確かめます。

| # | 確かめること | やり方 | 結果 |
|---|---|---|---|
| 1 | 入力欄を押しても、画面が勝手に拡大されない | ＋追加 → タイトル欄を押す | ☐ |
| 2 | 指で広げると拡大できる | 月の表を 2 本指で広げる | ☐ |
| 3 | キーボードが出ても、入力中の文字が見える | ＋追加 → いちばん下の「メモ」を押して文字を打つ | ☐ |
| 4 | いちばん大きい字でも、時刻や日付が切れない | 設定 → 文字の大きさを最大 → 月・週・日・予定の画面を見る | ☐ |
| 5 | 通知が届く | 35 分後に始まる予定を、通知「30分前」だけにして入れ、5 分ほど待つ（Google カレンダーのアプリから届く） | ☐ |
| 6 | 電波がなくても予定が見える | 機内モードにして、ホーム画面のアイコンから開く | ☐ |
| 7 | 電波がない間に入れた予定が、戻したら Google に入る | 機内モードのまま予定を入れる（「まだ保存中」と出る）→ 機内モードを切る → アプリを開き直す → Google カレンダーのアプリに出る | ☐ |
| 8 | 予定の時刻が、入れたとおりに出る | 場所付きの予定を入れ、「出発の目安」とは別に予定の時刻が大きく出ていることを確かめる | ☐ |
| 9 | 毎晩の控えができている | 次の日、スプレッドシートに「控え_日付」のシートがある | ☐ |

## 8. 困ったとき

### アプリに「接続の設定が正しくありません」と出る／iPhone をなくした

合言葉を作り直します。古い合言葉は使えなくなります。

1. パソコンで Apps Script を開き、関数の選択欄で **`reissueKey`** を選んで **実行**。
2. 実行ログに出た「新しい合言葉」を控えます。
3. iPhone のアプリで **設定** → **家族向けの設定** → **接続をやり直す** → URL と新しい合言葉を入れて **つなぐ**。

### アプリの更新

- **アプリの画面**: main に入れると自動で公開されます。iPhone では、次にアプリを開いたとき（またはアプリに戻ってきたとき）に新しい版に切り替わります。入力の途中では切り替わりません。
- **Google 側（Apps Script）**: 設定 → 家族向けの設定 に「**Google 側の更新が必要です**」と出たら、次のようにします。
  1. 2-2 と同じように、`gas/dist/Code.gs`（と `gas/appsscript.json` が変わっていればそれも）を貼り直して保存します。
  2. **デプロイ** → **デプロイを管理** → 鉛筆の印（**編集**）→ バージョンを **新バージョン** にして → **デプロイ**。
  3. URL は変わらないので、iPhone の入れ直しは不要です。

  > 「新しいデプロイ」を押すと URL が変わってしまいます。更新のときは「デプロイを管理」から行ってください。

### 消してしまった予定を戻したい

- **30 日以内なら**: Google カレンダー（パソコンのブラウザ）の右上の **設定（歯車）** → **ゴミ箱** から戻せます。
- **控えから戻す**: スプレッドシートを開き、「控え_日付」のシートで戻したい予定の行を選んで、上のメニュー **ただしカレンダー** → **選んだ行の予定を戻す**。
  （メニューが出ていないときは、スプレッドシートを開き直します）

### 移動時間が出ない

- 自宅の住所が登録されているか確かめます（5 章）。
- 場所の名前で見つからないときは、予定の **場所** で **地図で探す** を使うか、住所を入れます。
- 1 日に計算できる回数に上限があります（無料の範囲に収めるため）。翌日にはまた計算できます。予定の画面の **計算し直す** で、もう一度計算できます。

### 天気が出ない

天気予報は 16 日先までです。それより先の予定は、近くなったら出ます。電波がないときも出ません。

### 「まだ保存中」が消えない

電波のよいところでアプリを開き直すと、自動で送られます。何日も消えないときは、合言葉が変わっていないか（上の「接続の設定が正しくありません」）を確かめます。
